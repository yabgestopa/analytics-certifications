# dbt Certification Prep

Study notes and hands-on practice for the **dbt Analytics Engineering Certification**
(exam version 1.11), built on dbt Core + BigQuery with dbt's Jaffle Shop sample data.

- `docs/EXAM_GUIDE.md`: the official exam topics as a checklist
- `docs/STUDY_LOG.md`: what I did and learned in each session

Sister project: [harbour-analytics](https://github.com/yabgestopa/harbour-analytics), a
Xero → Fivetran → BigQuery → dbt → Power BI pipeline.
